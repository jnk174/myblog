# Hello World! Gill's Log의 첫 번째 게시글입니다.

> [!NOTE]
> **디자인 철학**: 이 블로그는 **Bold Tech** 테마를 기반으로, 가독성과 성능을 극대화하도록 설계되었습니다.

드디어 나만의 공간인 **Gill's Log**를 런칭했습니다! 🎉 
이 블로그는 단순한 정보 저장소를 넘어, 제가 배운 지식과 경험을 정제하여 공유하는 소중한 공간이 될 것입니다.

## 왜 블로그를 만들었나요?

1.  **지식의 기록**: 배운 것은 기록하지 않으면 잊혀집니다.
2.  **공유의 즐거움**: 제가 겪은 시행착오가 누군가에게 도움이 되었으면 합니다.
3.  **기술적 도전**: Next.js와 Shadcn UI를 활용해 직접 이 공간을 빚어보고 싶었습니다.

## 앞으로 어떤 내용을 다룰까요?

- **Frontend**: Next.js, React, Tailwind CSS 등 최신 웹 기술
- **Backend/Tooling**: Vercel, Node.js, Git 등
- **Personal**: 개발자로서의 일상과 인사이트

> [!TIP]
> 상단의 다크 모드 토글을 이용해 밤에도 편안하게 글을 읽어보세요.

자, 이제 본격적으로 시작해 보겠습니다!
