# 엑셀 INDEX MATCH 다중 조건 공식, 다시 잊지 않기 위한 기록

엑셀에서 값을 찾아올 때 저는 `VLOOKUP`보다 `INDEX + MATCH` 조합을 더 자주 사용합니다. 왼쪽 방향으로도 값을 가져올 수 있고, 조회 열과 반환 열의 위치가 바뀌어도 공식이 비교적 안정적이기 때문입니다.

그런데 이상하게도 조건이 하나일 때는 손이 기억하는데, 조건이 두 개로 늘어나는 순간 공식 구조가 자꾸 흐려집니다. 특히 `MATCH(1, 조건1 * 조건2, 0)` 형태를 떠올리기까지 매번 시간이 걸립니다.

이번에는 제가 자주 쓰는 조회 패턴을 세 가지로 나누어 정리해 두었습니다.

![엑셀 INDEX MATCH 다중 조건 예시 화면](/images/blog/excel_index_match_two_criteria_mockup.svg)

*부서와 이름을 동시에 만족하는 행을 찾아 금액을 가져오는 INDEX MATCH 예시*

---

## 1. 먼저 단일 조건 INDEX MATCH 복습

가장 기본 형태는 아래와 같습니다.

```excel
=INDEX(가져올_범위, MATCH(찾을값, 찾을_범위, 0))
```

예를 들어 아래와 같은 표가 있다고 가정합니다.

| 부서 | 이름 | 금액 |
| :--- | :--- | ---: |
| 영업 | 김민수 | 120 |
| 기획 | 이서연 | 180 |
| 개발 | 박준호 | 250 |

`이서연`의 금액을 가져오고 싶다면 공식은 이렇게 됩니다.

```excel
=INDEX(C2:C4, MATCH("이서연", B2:B4, 0))
```

제 방식으로 풀어 쓰면 이렇습니다.

| 함수 | 역할 |
| :--- | :--- |
| `MATCH("이서연", B2:B4, 0)` | `B2:B4`에서 이서연이 몇 번째에 있는지 찾습니다. |
| `INDEX(C2:C4, 찾은위치)` | `C2:C4`에서 같은 위치의 값을 가져옵니다. |

즉, `MATCH`가 행 번호를 찾고, `INDEX`가 그 행의 결과값을 꺼내는 구조입니다.

---

## 2. 조건이 두 개일 때의 핵심 공식

제가 자주 잊어버리는 부분은 여기입니다. 조건이 두 개일 때는 `MATCH`의 찾을값을 `1`로 두고, 조건들을 곱해서 맞는 행을 찾습니다.

```excel
=INDEX(가져올_범위, MATCH(1, (조건범위1=조건값1) * (조건범위2=조건값2), 0))
```

예를 들어 같은 이름이 여러 부서에 있을 수 있는 표를 생각해 보겠습니다.

| 부서 | 이름 | 금액 |
| :--- | :--- | ---: |
| 영업 | 김민수 | 120 |
| 기획 | 이서연 | 180 |
| 영업 | 이서연 | 210 |
| 개발 | 박준호 | 250 |

여기서 `영업` 부서의 `이서연` 금액을 가져오고 싶다면 이렇게 씁니다.

```excel
=INDEX(C2:C5, MATCH(1, (A2:A5="영업") * (B2:B5="이서연"), 0))
```

이 공식에서 가장 중요한 생각은 이것입니다.

- 조건이 맞으면 `TRUE`, 틀리면 `FALSE`가 됩니다.
- `TRUE`는 `1`, `FALSE`는 `0`처럼 계산됩니다.
- 두 조건을 곱하면 둘 다 `TRUE`인 행만 `1`이 됩니다.
- `MATCH`는 그 `1`의 위치를 찾습니다.

위 예시는 내부적으로 이런 식으로 계산된다고 이해하면 됩니다.

| 부서 조건 | 이름 조건 | 곱한 결과 |
| :---: | :---: | :---: |
| TRUE | FALSE | 0 |
| FALSE | TRUE | 0 |
| TRUE | TRUE | 1 |
| FALSE | FALSE | 0 |

결국 `MATCH(1, ..., 0)`은 두 조건을 모두 만족하는 세 번째 행을 찾고, `INDEX(C2:C5, 3)`이 되어 `210`을 가져옵니다.

> 💡 핵심 요약: 다중 조건 INDEX MATCH는 `MATCH`가 값을 직접 찾는 것이 아니라, 조건을 모두 만족해서 `1`이 된 행을 찾는 구조입니다.

---

## 3. 행 조건과 열 조건이 따로 있을 때

이번에는 데이터가 세로 목록이 아니라, 행과 열이 교차하는 표라고 생각해 보겠습니다.

| 이름 | 1월 | 2월 | 3월 |
| :--- | ---: | ---: | ---: |
| 김민수 | 120 | 130 | 125 |
| 이서연 | 180 | 210 | 205 |
| 박준호 | 250 | 240 | 260 |

여기서 `이서연`의 `2월` 값을 가져오고 싶다면 공식은 이렇게 됩니다.

```excel
=INDEX(B2:D4, MATCH("이서연", A2:A4, 0), MATCH("2월", B1:D1, 0))
```

이 구조는 앞의 다중 조건 공식과 생각하는 방향이 조금 다릅니다.

| 부분 | 역할 |
| :--- | :--- |
| `INDEX(B2:D4, 행번호, 열번호)` | 전체 값 범위에서 행과 열이 만나는 값을 가져옵니다. |
| `MATCH("이서연", A2:A4, 0)` | 몇 번째 행인지 찾습니다. |
| `MATCH("2월", B1:D1, 0)` | 몇 번째 열인지 찾습니다. |

즉, 행 조건과 열 조건이 따로 있을 때는 아래 공식 하나로 기억하면 됩니다.

```excel
=INDEX(값범위, MATCH(행조건, 행머리글범위, 0), MATCH(열조건, 열머리글범위, 0))
```

제가 자주 헷갈리는 지점은 이 두 공식을 섞어버리는 것입니다.

| 상황 | 공식 구조 |
| :--- | :--- |
| 같은 행에서 조건 2개를 동시에 만족해야 할 때 | `MATCH(1, 조건1 * 조건2, 0)` |
| 행 조건 1개와 열 조건 1개가 교차할 때 | `INDEX(값범위, 행MATCH, 열MATCH)` |

> 💡 핵심 요약: 조건이 모두 세로 방향의 행을 찾는 조건이면 `MATCH(1, 조건1 * 조건2, 0)`이고, 행과 열이 교차하는 표라면 `MATCH`를 행용, 열용으로 각각 한 번씩 씁니다.

---

## 4. 행 조건은 여러 개, 열 조건도 있는 경우

실제로는 두 방식이 섞이는 경우도 있습니다. 예를 들어 행에서는 `부서`와 `이름`을 모두 만족해야 하고, 열에서는 `월`을 골라야 하는 상황입니다.

| 부서 | 이름 | 1월 | 2월 | 3월 |
| :--- | :--- | ---: | ---: | ---: |
| 영업 | 김민수 | 120 | 130 | 125 |
| 기획 | 이서연 | 180 | 190 | 185 |
| 영업 | 이서연 | 200 | 210 | 205 |
| 개발 | 박준호 | 250 | 240 | 260 |

`영업` 부서의 `이서연`이 받은 `2월` 금액을 가져오려면 이렇게 씁니다.

```excel
=INDEX(C2:E5, MATCH(1, (A2:A5="영업") * (B2:B5="이서연"), 0), MATCH("2월", C1:E1, 0))
```

이 공식은 이렇게 나누어 보면 덜 무섭습니다.

| 부분 | 역할 |
| :--- | :--- |
| `C2:E5` | 실제 값이 들어 있는 범위입니다. |
| `MATCH(1, (A2:A5="영업") * (B2:B5="이서연"), 0)` | 부서와 이름을 모두 만족하는 행을 찾습니다. |
| `MATCH("2월", C1:E1, 0)` | 2월이 몇 번째 열인지 찾습니다. |

정리하면, `INDEX` 안에는 결국 **값범위, 행번호, 열번호**가 들어갑니다.

```excel
=INDEX(값범위, 행번호, 열번호)
```

행번호가 단순하면 `MATCH("이서연", A2:A4, 0)`이고, 행번호에 조건이 여러 개 필요하면 `MATCH(1, 조건1 * 조건2, 0)`로 바뀌는 것입니다.

---

## 5. 제가 자주 틀리는 포인트

공식 자체는 짧지만, 실제로 쓰다 보면 실수하는 지점이 꽤 반복됩니다.

### 1. 범위 크기를 서로 다르게 잡는 실수

아래처럼 범위 길이가 다르면 문제가 생깁니다.

```excel
=INDEX(C2:C5, MATCH(1, (A2:A6="영업") * (B2:B5="이서연"), 0))
```

`INDEX`의 반환 범위, 첫 번째 조건 범위, 두 번째 조건 범위는 모두 같은 행 범위를 바라봐야 합니다.

```excel
=INDEX(C2:C5, MATCH(1, (A2:A5="영업") * (B2:B5="이서연"), 0))
```

### 2. 조건을 더하기와 곱하기 중 헷갈리는 실수

제가 찾는 것은 보통 `부서도 맞고 이름도 맞는` 행입니다. 이럴 때는 곱하기(`*`)를 씁니다.

| 연산 | 의미 |
| :--- | :--- |
| `조건1 * 조건2` | 조건1도 맞고 조건2도 맞아야 합니다. |
| `조건1 + 조건2` | 조건1 또는 조건2 중 하나만 맞아도 됩니다. |

제가 실무에서 자주 쓰는 것은 대부분 `AND` 조건이라서 `*`를 먼저 떠올리면 됩니다.

### 3. 전체 열 참조를 습관처럼 쓰는 실수

아래처럼 전체 열을 잡으면 보기에는 편하지만, 파일이 커졌을 때 느려질 수 있습니다.

```excel
=INDEX(C:C, MATCH(1, (A:A="영업") * (B:B="이서연"), 0))
```

가능하면 실제 데이터 범위나 표(Table)를 기준으로 잡는 편이 낫습니다.

```excel
=INDEX(C2:C1000, MATCH(1, (A2:A1000="영업") * (B2:B1000="이서연"), 0))
```

## 6. 다음에 바로 떠올릴 나의 체크리스트

다음에 또 공식이 기억나지 않으면 아래 순서대로 생각하기로 했습니다.

1. **무엇을 가져올 것인가?**  
   `INDEX(가져올_범위, ...)`부터 적습니다.

2. **행만 찾으면 되는가, 행과 열을 모두 찾아야 하는가?**  
   조건이 모두 행을 찾는 조건이면 `MATCH(1, 조건1 * 조건2, 0)`을 떠올립니다.

3. **각 조건은 TRUE/FALSE 배열인가?**  
   `(부서범위=부서값) * (이름범위=이름값)`처럼 괄호를 꼭 씁니다.

4. **열도 찾아야 하는가?**  
   월, 구분, 항목처럼 가로 방향 조건이 있으면 열용 `MATCH`를 하나 더 씁니다.

5. **모든 범위의 행 수가 같은가?**  
   `C2:C100`, `A2:A100`, `B2:B100`처럼 시작과 끝을 맞춥니다.

최종 암기용 공식은 두 가지입니다.

```excel
=INDEX(결과범위, MATCH(1, (조건범위1=조건값1) * (조건범위2=조건값2), 0))
```

```excel
=INDEX(값범위, MATCH(행조건, 행머리글범위, 0), MATCH(열조건, 열머리글범위, 0))
```

## 맺음말

엑셀 공식은 한 번 이해했다고 끝나는 것이 아니라, 자주 쓰는 모양을 제 손에 익히는 일이 더 중요한 것 같습니다. `INDEX MATCH`도 마찬가지입니다. 단일 조건은 익숙하지만 다중 조건은 매번 검색하게 된다면, 아직 제 안에 완전히 자리 잡지 않은 공식이라는 뜻이겠지요.

다음에 또 조건이 두 개 이상인 조회식을 만나면, 일단 이렇게 떠올리기로 했습니다.

- 결과는 `INDEX`가 가져옵니다.
- 위치는 `MATCH`가 찾습니다.
- 조건이 여러 개면 `TRUE/FALSE`를 곱해서 `1`을 만듭니다.
- 행과 열이 나뉘면 `MATCH`를 두 번 씁니다.

이 정도만 기억해도 다시 처음부터 헤매지는 않을 것 같습니다.
