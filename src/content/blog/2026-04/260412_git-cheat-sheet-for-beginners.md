# 🎮 Git, 게임 저장(Save) 포인트라고 생각하세요!

처음 개발을 시작하면 가장 먼저 마주하는 거대한 벽 중 하나가 바로 **Git(깃)**입니다. 복잡한 터미널 창에 영어 명령어들을 입력하다 보면 "내 코드가 다 날아가면 어쩌지?" 하는 공포가 엄습하기도 하죠.

하지만 걱정 마세요. Git은 사실 여러분이 즐겨 하는 게임의 **'저장 포인트'** 혹은 **'타임머신'**과 같습니다. 중요한 순간에 '저장'을 해두고, 나중에 실수했을 때 그 시점으로 '되돌리기' 위해 사용하는 도구일 뿐입니다.

오늘은 가장 많이 쓰이는 Git 명령어를 초보자 눈높이에서 아주 쉽게 정리해 드릴게요.

---

## 🛠️ Git의 기본 흐름 (The Workflow)

명령어를 배우기 전에, 딱 세 단계만 기억하세요.

1.  **장바구니 담기 (add)**: 저장할 파일을 고릅니다.
2.  **포장하기 (commit)**: 어떤 내용을 바꿨는지 메모를 남겨 저장합니다.
3.  **내보내기 (push)**: 내 컴퓨터에 저장된 내용을 깃허브(온라인 저장소)로 올립니다.

## 📜 깃(Git) 핵심 명령어 치트 시트

### 1. 시작하기 (Initialization)
새로운 게임을 시작할 때 '새 슬롯'을 만드는 명령어입니다.

| 명령어 | 설명 | 언제 쓰나요? |
| :--- | :--- | :--- |
| `git init` | 깃 시작! | 폴더를 처음 만들고 깃으로 관리하고 싶을 때 |
| `git clone [주소]` | 저장소 복제 | 남의 코드나 기존 내 코드를 내 컴퓨터로 가져올 때 |

### 2. 저장하기 (Save Logic)
파일을 수정하고 나서 '저장 포인트'를 만드는 과정입니다.

| 명령어 | 설명 | 언제 쓰나요? |
| :--- | :--- | :--- |
| `git status` | 현재 상태 체크 | 지금 어떤 파일이 바뀌었는지 궁금할 때 |
| `git add [파일명]` | 장바구니에 담기 | 특정 파일 하나만 저장하고 싶을 때 |
| `git add .` | 다 담아! | 바뀐 모든 파일을 한꺼번에 저장하고 싶을 때 |
| `git commit -m "메시지"` | 저장 및 메모 | 저장 포인트를 만들고 무엇을 했는지 기록할 때 |

### 3. 주고받기 (Online Sync)
내 컴퓨터와 깃허브 사이를 연결하는 명령어입니다.

| 명령어 | 설명 | 언제 쓰나요? |
| :--- | :--- | :--- |
| `git push` | 온라인 업로드 | 내 컴퓨터의 저장 내용을 깃허브로 보낼 때 |
| `git pull` | 온라인 다운로드 | 깃허브의 바뀐 내용을 내 컴퓨터로 가져올 때 |

### 4. 과거 여행 (History)
타임머신을 타고 과거를 확인하는 방법입니다.

| 명령어 | 설명 | 언제 쓰나요? |
| :--- | :--- | :--- |
| `git log` | 저장 기록 보기 | 지금까지 어떤 저장을 했는지 목록을 볼 때 |
| `git checkout [아이디]` | 과거로 뿅! | 특정 저장 시점으로 코드를 되돌려보고 싶을 때 |

## 💡 초보자를 위한 Git 꿀팁!

1.  **메시지는 정성껏**: `git commit -m "update"` 보다는 `git commit -m "로그인 기능 버그 수정"` 처럼 적어주세요. 미래의 여러분이 과거의 자신을 원망하지 않게 됩니다.
2.  **status를 친구처럼**: 뭔가 잘 안된다 싶으면 일단 `git status`를 쳐보세요. 깃이 지금 무엇이 문제인지 친절하게 알려줍니다.
3.  **무조건 push 하지 마세요**: 코드가 잘 돌아가는지 확인하고(Save), 그 다음에 push 하세요.
